    GPUI.Builder (gpui v0.2.0-rc.2)

    Copy Markdown View Source

    Programmatic builders for immutable GPUI.Element trees.

    Most views use the ~GPUI template sigil. Import this module explicitly when pipe-style construction is a better fit for generated or data-driven trees.
