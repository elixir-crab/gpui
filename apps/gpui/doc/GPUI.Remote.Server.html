    GPUI.Remote.Server (gpui v0.2.0-rc.2)

    Copy Markdown View Source

    SafeRPC endpoint for renderer-independent GPUI application sessions.

    Every remote session owns a distinct GPUI.Session. The server never starts a native display; rendering happens only on the connected display client.

    Options

    • :app - required GPUI.Application module;
    • :args - default mount argument used when a client omits one;
    • :port - listening port, defaulting to 0 for an OS-assigned port;
    • :ssl - false or TLS listener options;
    • :session_ttl - inactivity timeout in milliseconds or :infinity, defaulting to 30 minutes;
    • :max_in_flight_requests_per_connection - positive limit up to 4,096, defaulting to 64;
    • :max_in_flight_requests_per_session - positive limit up to 4,096, defaulting to 16;
    • :name - optional supervisor name.
