# `GPUI`
[🔗](https://github.com/elixir-crab/gpui/blob/v0.2.0-rc.2/../../../../apps/gpui/lib/gpui.ex#L1)

Elixir-facing entry point for GPUI applications and views.

Views normally use `GPUI.Template` through `use GPUI.View`. Programmatic
element construction is available explicitly from `GPUI.Builder`.
